プログラミングを無料で学べるサービスはたくさんあります。ただ、「無料」と書かれていても、**全部の講座が無料のもの**、**一部だけ無料のもの**、**学校を通せば無料になるもの**が混ざっています。この記事では、日本の学生が無料トライアルに頼らず学べるサービスを、公式情報をもとに比べます。

:::warning この記事の情報について
講座の範囲、動画や演習の数、認定の条件、学校向けの制度、年齢条件、画面の言語は変更されることがあります。内容は2026年10月4日時点の情報に基づいています。「未確認」と書いた項目は、確認できた範囲では明記が見つからなかったもので、可能・不可能のどちらとも断定していません。始める前に、必ず公式ページを確認してください。
:::

## 結論：目的別の入口

- **完全に無料で長く続けたい**：freeCodeCamp。公式は、コース、プロジェクト、認定証を含むすべてが100％無料と案内しています。日本語のカリキュラムもあります。
- **日本語の短い動画と演習で始めたい**：paizaラーニングの「完全無料」の講座。ただし、すべての講座が無料ではありません。
- **完全な初心者・中学生**：Code.org。日本語で、K-12向けのコンピュータサイエンスやAIの教材が無料で提供されています。
- **Webサイトを作って公開したい**：freeCodeCampとMDN Web Docsの組み合わせ。

:::note 学習サイトは「1つを主教材にする」
いくつものサービスに登録しただけで止まってしまうことがよくあります。主教材を1つ決めて、ほかは「困ったときに調べる辞書」として使うのがおすすめです。
:::

## 「無料」の区分を分けて考える

| 区分 | 意味 | 例 |
| --- | --- | --- |
| 完全無料 | コースから認定まで有料プランがない | freeCodeCamp |
| 無料の講座あり | 完全無料の講座があるが、全講座は無料ではない | paizaラーニング |
| 一部が無料 | フリープランで見られる範囲が決まっている | ドットインストール、Progate（初級編） |
| 無料の公開ドキュメント | 無料で読める。進捗管理や添削はない | MDN、Python公式チュートリアル |
| 学校経由で全講座が無料 | 学校や先生が申請する制度 | paiza学校フリーパス |
| 無料トライアル | 期間限定の体験版。この記事では継続無料としては扱わない | paizaなどの初月無料の案内 |

## サービスごとの特徴

### freeCodeCamp

非営利の公益法人が運営し、寄付で支えられています。HTML、CSS、JavaScript、Python、Linux、Git、SQL、データ分析、機械学習などを扱います。有料のプランが公式案内には見当たらないため、費用をかけられない学生が長期の計画を立てやすいのが利点です。

注意点は、日本語化の範囲がコースによって違う可能性があることと、認定の取得には相応の時間がかかることです。認定証だけを目標にせず、**完成したプロジェクトを自分で説明し、改造できる状態**にしましょう。

### paizaラーニング

約3分の動画と演習で、Python、Java、JavaScript、C言語などを学べます。「完全無料」と表示された講座があり、環境構築なしで始められます。

ただし、**無料の範囲と有料の範囲は明確に違います。** 公式の有料プラン案内では、無料プランは動画943本、演習1,223問などと案内され、有料プランではさらに多くの動画と演習、解答コードの閲覧などが使えます。この数字は掲載時点のもので、増減する可能性があります。「一部無料」の講座と「完全無料」の講座、無料プランと「初月無料」のキャンペーンを混同しないでください。

### paiza学校フリーパス

小学校から大学・専門学校までの学校を通じて、全講座を無料で提供する制度です。**個人が自動で使えるものではなく**、学校や教員の申請、審査、クーポンの発行が必要な場合があります。過去の公式案内では、対象期間は申込年度の4月から翌年3月で、翌年度は再申請が必要とされています。最新の制度、対象校、手続きは、公式のフリーパスのページで確認してください。使いたい場合は、先生にこの制度を紹介して、学校として申請できるか相談しましょう。

### ドットインストール

3分の動画レッスンで、Web制作、ゲーム制作、PHP、Ruby、Pythonなどの入門を扱います。フリープランでは、無料レッスンの動画、無料レッスンのミニクイズ、学習記録が使えます。全レッスンが無料ではなく、プレミアムの機能を無料と誤解しないようにしましょう。無料のレッスンだけで進めると、学習の順番が有料の部分で途切れることがあります。その場合は、MDNやfreeCodeCampなどで補いましょう。

### MDN Web Docs

HTML、CSS、JavaScript、アクセシビリティ、デザイン、バージョン管理を学べる、日本語のドキュメントです。「初めてのウェブサイト」のチュートリアルは、計画、HTML、CSS、JavaScript、公開までを扱います。動画講座のような進捗管理、添削、修了証はありません。**読むだけで終わらせず、自分のページを作ってブラウザで動かし、Gitに保存して公開まで進める**のが大切です。

### Python公式チュートリアル

日本語で無料で読めますが、プログラミングが全く初めての人向けではなく、一般的なプログラミングの基礎を前提としていると明記されています。最初は、paizaやfreeCodeCampなどの演習型の教材で基本を作ってから、「文法や標準機能を正確に調べる辞書」として使いましょう。

### Microsoft Learn

C#、.NET、Azure、GitHub、AI・データなどを、日本語の無料のモジュールで学べます。注意したいのは、**学習が無料でも、Azureの実環境の利用は別**という点です。クラウドを使う演習の前に、サンドボックスの有無、無料枠、支払い情報、不要なリソースの削除方法を確認してください。認定試験は別料金の場合があります。

### Code.org

非営利団体が運営し、K-12向けのコンピュータサイエンス、AI、データサイエンスの教材を無料で提供しています。ブロック型のプログラミングが中心で、完全な初心者や中学生、学校での学習に向いています。興味が出たら、PythonやJavaScript、HTML/CSSなどのテキストの言語へ段階的に進みましょう。

### Google's Python Class

Googleが提供する無料の教材で、文章、動画、コードの演習があります。ただし、少しプログラミング経験がある人向けで、主に英語です。日本語が必須の初心者の主教材にはせず、英語も読める経験者の追加演習として使うのがよいでしょう。

### Progate

各レッスンの初級編が無料で、中級以降は月額課金です。「全カリキュラムを完全無料で学べる」サービスではないため、初級の導入に使い、その後は無料の教材や自作のプロジェクトに移るのが現実的です。

## 目的別の学習順

| 目的 | おすすめの順番 |
| --- | --- |
| 完全な初心者 | Code.org、またはpaizaの完全無料講座から始め、慣れたらテキストの言語へ |
| Webサイトを作って公開したい | freeCodeCampのHTML/CSS、MDNの「初めてのウェブサイト」、Gitで保存、無料のホスティングで公開 |
| Pythonで道具やAI活用を作りたい | paizaの完全無料のPython講座、freeCodeCamp、Python公式チュートリアルで文法を確認 |
| C#や.NETを学びたい | Microsoft Learnで基礎、ローカルでコンソールアプリを作る |
| 学校で全講座を使いたい | 先生にpaiza学校フリーパスを紹介して相談。Code.orgも併用 |

## 学生が4週間で最初の作品を作る流れ

:::steps 4週間の計画
1. 作りたい小作品を1つ決めます。例：自己紹介サイト、学習記録ツール、英単語クイズ。
2. 目的に合う主教材を1つ選び、公式ページで無料の範囲、有料のコース、年齢、アカウントの条件を確認します。
3. 1日30分から始め、1回30〜60分、週に3〜5回の学習時間を決めます。
4. 動画や記事を見たら、**必ずその直後に自分でコードを書いて実行**します。
5. 週に1回、学んだ内容だけで小さなプログラムかWebページを作ります。
6. コードをGitかローカルのフォルダに保存し、READMEに目的と使い方を書きます。
7. 4週間後に作品を1つ公開するか人に見せて、改善点を記録し、次のテーマを選びます。
:::

## 無料のまま続けるための注意

- **「一部無料」の講座を避ける**：paizaでは、まず「完全無料」の一覧から選びます。
- **初月無料などのボタンを押さない**：支払い情報や自動更新が関係する可能性があります。
- **クラウドの演習は終わったら片付ける**：作ったリソースを削除し、利用状況を確認します。
- **自分のコードは自分で保存する**：学習サービスの進捗だけに頼らず、パソコンとGitに残します。
- **認定証だけを実績にしない**：動く作品、ソースコード、説明文、スクリーンショットを残します。

## 著作権と個人情報

- 学習サービスを無料で使えることと、**教材を転載・再販売してよいこと**は別です。動画、スライド、問題文、模範解答、ロゴを、ブログやSNS、販売する教材に載せる前に、各サービスの規約とライセンスを確認してください。
- 自分で書いたプログラムでも、コピーしたコード、外部のライブラリ、画像、フォント、データ、APIの規約が関係します。
- ポートフォリオでは、教材を再現しただけの作品よりも、「自分が変えた点」「自分で追加した機能」「学んだこと」を明記しましょう。
- 学習用アカウントのプロフィールに、本名、学校名、住所、電話番号、行動の予定を載せないでください。
- GitHubなどにコードを公開するときは、APIキー、パスワード、トークン、`.env` ファイル、個人データを入れないようにします。
- 年齢の条件や保護者の同意は、サービスごとに確認してください。
