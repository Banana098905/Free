Python、Web制作、AIツール、個人開発などの実績は、バラバラの場所に置いたままだと見てもらえません。ポートフォリオサイトは、それらを一か所にまとめて見せるための名刺代わりのページです。進学、コンテスト、将来の案件応募、共同開発の募集などで使えます。

この記事は、無料で始めたい日本の学生向けに、**公開先を選ぶときの考え方**と**最初に載せる内容**を整理したものです。

:::warning この記事の情報について
サービスの無料枠や規約は変更されることがあります。この記事の内容は2026年10月3日時点の調査に基づいており、個別のサービスの条件は、利用前に必ず公式サイトで確認してください。記事の最後に、確認に使った公式情報源を載せています。
:::

## 先に知っておきたい大事なこと

無料の公開サービスでは、次の2つが**別の話**になっています。

- 作品紹介やポートフォリオを公開できるか
- 商用サービス（オンライン事業、ECサイト、SaaSなど）を運営できるか

たとえばGitHub Pagesは、個人・組織・プロジェクトのWebサイトをGitHubのリポジトリから公開できます。一方で、公式ドキュメントでは、オンライン事業、ECサイト、SaaSなど、主に商取引を促進する目的の無料ホスティングとしては意図されておらず、許可されないとされています。

つまり、**ポートフォリオ、技術ブログ、プロジェクト紹介の公開先としては候補になりますが、商用サービス本体の置き場所として安易に選ぶのは避ける**のが安全です。将来、商用サービスを公開する段階になったら、用途に合った公開先に移ることを前提にしておきましょう。具体的な候補と上限は[無料でWebサイトを公開できるサービス比較](/articles/free-website-hosting-comparison)にまとめています。

## 公開先を比べるときの見方

候補を比べるときは、次の列を表にして並べると、あとで困りにくくなります。

| 確認する項目 | 見るポイント |
| --- | --- |
| ポートフォリオ公開 | 規約上、個人の作品紹介に使えるか |
| ブログ公開 | 制作記録や技術記事を載せられるか |
| 商用サービスの運営 | SaaS・ECなどを運営してよいか（ポートフォリオとは別に確認） |
| 決済ページ | 決済を伴うページを置いてよいか |
| 独自ドメイン | 使えるか。費用がかかるか |
| 上限 | 容量、帯域、ビルド回数などの制限 |
| 無料の種類 | 継続無料プランか、無料枠か、体験版（トライアル）か |
| クレジットカード | 登録時に必要か |

:::note 無料トライアルは候補に入れない
7日、14日、30日などの体験版は、継続して無料で使えるわけではありません。ポートフォリオのように長く置いておくものの公開先としては、候補から外しておくと安心です。
:::

## 最初にサイトへ載せる内容

最初から大きなサイトを作る必要はありません。小さく始めて、作品が増えたら足していきましょう。

:::steps ポートフォリオを作る流れ
1. 公開方法を選びます。上の表で、ポートフォリオの公開が規約上できるかを確認します。
2. 自己紹介を書きます。得意なこと、学んでいること、これから挑戦したいことを短くまとめます。
3. 作品を3件選びます。数より、説明のていねいさを優先します。
4. 各作品に「目的」「使った技術」「画面（スクリーンショット）」「学んだこと」を書きます。
5. 公開URLを整理し、デモやGitHubのリポジトリがあればリンクを置きます。
6. 制作記録をブログまたは制作ログとして残していきます。
:::

作品ごとに「どんな課題を、どうやって解決したか」と「うまくいかなかった点と、そこから学んだこと」を書くと、完成品だけを並べるよりも、あなたの取り組みが伝わります。

## 学生が気をつけたいこと

- **年齢条件**：アカウントを作るのに必要な最低年齢を確認します。18歳未満の場合は、保護者の同意が必要かどうかも確認しましょう。
- **公開してはいけない情報**：本名、学校名、住所、位置情報、顔写真などを不用意に載せないでください。公開ページは誰でも見られます。
- **アカウントの分け方**：学校のアカウントと個人のアカウントを混ぜないようにします。
- **収益を受け取る段階**：将来、収益を受け取る場合は、本人確認、口座、税務情報が必要になることがあります。その段階で、公開先・決済サービス・利用規約を改めて調べ直しましょう。
- **バックアップ**：無料プランは、縮小・終了・規約変更されることがあります。ソースコードや画像は、パソコンと別のクラウドなど、少なくとも2か所に保管しておくと安心です。クラウドの選び方は[無料クラウドストレージの選び方](/articles/free-cloud-storage-types)で整理しています。

## 作品づくりに使えるもの

ポートフォリオの中身を作る工程でも、無料でできることがあります。

| 工程 | できること | 注意点 |
| --- | --- | --- |
| 学習 | HTML、CSS、JavaScript、Pythonなどの基礎学習 | 修了証や高度な講座は有料の場合がある |
| 開発 | コード作成、静的サイト制作 | パソコンの性能、OSの条件、データのバックアップを確認する |
| 素材制作 | サムネイルや説明画像の作成 | 画像を作るツールの商用利用条件を確認する。入力した素材と生成物の権利は別に確認する |
| 文書化 | 企画書や作品説明書をPDFで作る | 個人情報や機密情報をオンライン変換サイトに上げない |
| 保存 | 資料、画像、PDFの保管 | 容量、ファイルサイズ、共有リンク、削除条件を確認する |
| 公開 | 作品紹介やデモページの公開 | 商取引や決済、SaaS運営が規約上できるかを別に確認する |

関連：[無料でPDFを編集する方法](/articles/free-pdf-editing)、[無料で使えるAIツールの活用方法](/articles/free-ai-tools-guide)

## まとめ

- ポートフォリオの公開と、商用サービスの運営は、規約上別のこととして確認する。
- 比較表には「ポートフォリオ可」「ブログ可」「商用サービス可否」「決済ページ可否」を別々の列で置く。
- 最初は自己紹介と作品3件から。説明をていねいにする。
- 公開する情報は慎重に選び、データは2か所に保管する。
