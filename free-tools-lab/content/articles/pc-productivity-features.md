作業を速くしようとして、新しいツールを探していませんか。実は、MacにもWindowsにも、最初から入っている便利な機能がたくさんあります。無料で、追加のインストールも要らないので、まずはここから試すのがおすすめです。

## まず覚えたい基本のショートカット

ショートカットキーは、マウスで探す手間を減らす、いちばん手軽な効率化です。

| やりたいこと | Mac | Windows |
| --- | --- | --- |
| コピー・貼り付け・元に戻す | Command + C / V / Z | Ctrl + C / V / Z |
| アプリを切り替える | Command + Tab | Alt + Tab |
| スクリーンショットを撮る | Command + Shift + 5 | Windows + Shift + S |
| アプリやファイルを検索する | Command + Space | Windows キーを押して入力 |

:::note キー操作は環境で異なる場合があります
OSのバージョンや設定によって、動作や名称が異なることがあります。うまく動かないときは、システム設定（Windowsでは設定）でキーボードやショートカットの項目を確認してください。
:::

## 検索機能で「探す時間」を減らす

ファイルやアプリを、フォルダをたどって探していませんか。MacのSpotlightや、Windowsのスタートメニューの検索なら、名前の一部を入力するだけで開けます。

:::steps 検索でアプリやファイルを開く
1. 検索を呼び出します（Macは Command + Space、Windowsは Windows キー）。
2. 開きたいアプリやファイルの名前の一部を入力します。
3. 候補が表示されたら、矢印キーで選び、Enterキーで開きます。
:::

## ウィンドウを整理する

2つのウィンドウを左右に並べて、資料を見ながら入力する作業は多いものです。Windowsでは「Windows キー + 左右の矢印キー」で、ウィンドウを画面の半分に寄せられます。Macでは、ウィンドウの左上の緑のボタンから、画面の左右に並べるメニューを使える場合があります。

## よく使う文章を登録する（テキスト置換）

メールの署名や、よく使う定型文は、短い文字を入力すると長い文章に置き換わるように登録できます。Macではキーボードの設定内にテキストを置き換える項目があります。Windowsには同じ名前の標準機能はなく、利用しているアプリ側の機能や、別の無料ツールを検討する形になります。

## 小さな工夫を積み重ねる

- ファイル名のルール（日付 + 内容）を決めておき、探しやすくする
- デスクトップにファイルを溜めず、週に1回、フォルダに整理する
- よく使うアプリは、ドックやタスクバーに固定する
- 毎日同じ操作をしているなら、「同じ操作を自動化できないか」を調べてみる

## 注意点

:::warning 設定を変える前に
システムの設定を変更するときは、変更前の状態をメモしておくと、元に戻しやすくなります。仕事用のパソコンでは、組織のルールで変更できない場合があります。
:::
